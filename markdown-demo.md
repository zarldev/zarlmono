# Markdown Demo

A quick tour of **Markdown formatting**, from *simple emphasis* to structured content.

## Text styles

You can write **bold**, *italic*, ***bold italic***, and ~~strikethrough~~ text. Use `inline code` for commands, variables, and filenames.

### A final note

Markdown keeps your writing **readable as plain text** while adding structure when rendered. Tables, task lists, and strikethrough depend on the renderer.
